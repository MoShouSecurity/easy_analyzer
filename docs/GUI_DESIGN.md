# Easy Analyzer 720p 桌面界面

现有 GUI 采用 Tauri 2 + React + TypeScript + Vite + Tailwind CSS，组件沿用 shadcn/ui 的本地组件与 Radix 交互模式。配色采用 Linear 风格的浅灰/白与分层深灰，蓝色主操作；侧栏为图标导航、选中底色与文字，表格使用轻分隔线、悬停和选中反馈。macOS 使用系统窗口控制。

## 窗口与密度

默认完整窗口 1280×720，最小 960×600；顶部 56px、侧栏 176px、底部 28px、工作区高 636px。默认详情 320px，可拖动调整到 280–440px，或收起使中央扩展。中央内边距 16px；按钮 32px、表格行 36px；正文 14px、表格/控件 13px，辅助说明 12px。路径、编号与原文使用等宽字体。中文备用字体为嵌入 Noto Sans CJK SC，许可证随源码及程序交付。

宽度低于 1200px 时详情为抽屉，低于 1024px 时导航为图标栏。表格与详情独立滚动，设置的应用/保存/检查连接固定在底部；导入高级选项独立滚动。隐藏字段可在详情完整查看。浅深主题保持相同控件、布局和数据。

## 八页

| 页面 | 内容 |
| --- | --- |
| 导入分析 | 文件拖放/选择、待分析文件、本机进程采集、采集目录；格式、Web 定义和输入限制折叠在高级选项；默认仅本地分析 |
| 分析概览 | 来源/证据/本地/AI 紧凑统计；风险和发现来源筛选；发现解释、核查建议、引用跳转 |
| 日志证据 | 关键词/正则、本地可疑交集、来源/类别/状态；当前页表格；解析字段、原文、来源详情 |
| 进程分析 | 快照来源独立树/列表；祖先上下文；孤儿和循环文字标记；命令、路径、用户在详情 |
| 网络分析 | 会话/数据包切换；完整会话包数与字节数、筛选命中数；选择会话查看关联包交集；元数据和十六进制详情 |
| AI 分析 | 全部/本地可疑/最近有效筛选；数量、模型、服务、每次载荷选项；运行历史和有效发现，原始回复折叠分页 |
| 报告与来源 | 完整报告导出、来源路径/格式/大小/SHA-256、诊断；导出弹窗选择格式与路径 |
| 设置 | 配置加载/应用/保存，服务/模型/密钥状态，独立新密钥输入、高级参数、主动检查连接 |

正常启动为空内存会话，无内置示例数字。运行截图使用合成导入文件及本机模拟 AI 服务，不是生图效果图；旧 1080p 效果图仅作为历史参考。

所有分页为后端分页，默认 100、可选 50/100/200。非法正则显示错误并保留有效结果。证据定位有返回入口；当前筛选 AI 覆盖完整集合，进程上下文不计入发送范围。未勾选原始包与载荷时不发送；每次运行后复选框清空。明确提示数据不自动脱敏。取消保留有效结果，未知总量使用活动指示。

不增加数据库、实时抓包、TCP 重组或 TLS 解密；保留 CLI、报告 schema 和现有发布流程。
